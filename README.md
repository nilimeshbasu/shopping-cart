# 🛒 TechStore Pro — Modern E-Commerce Platform

A feature-rich, high-performance e-commerce shopping cart web application built with **React**, **Context API**, and **useReducer**. It features dynamic product filtering, real-time cart calculations (including GST & promo codes), and sleek product animations.

🚀 **Live Demo:** [https://shoppingcart-zeta-green.vercel.app/](https://shoppingcart-zeta-green.vercel.app/)  
📁 **GitHub Repository:** [https://github.com/nilimeshbasu/shopping-cart](https://github.com/nilimeshbasu/shopping-cart)

---

## 🌟 Key Features

* **Dynamic Catalog & Search:** Search through products in real time and filter by categories like Flagship Phones, GPUs, Audio, and Accessories.
* **Real Product Showcase:** Integrated photography for flagship smartphones (iPhone 15 Pro Max, Galaxy S24 Ultra, Pixel 8 Pro) and GPUs (RTX 4090, RTX 4080 Super, RX 7900 XTX).
* **Robust State Management:** Managed globally via React's `Context API` and state reducer (`useReducer`).
* **Smart Cart System:**  
  * Add, increment, decrement, or remove items.
  * Real-time item count badge on navigation bar.
  * Interactive promo code discounts (`REACT10` for 10% off, `SAVE20` for 20% off).
  * Automated tax calculation (18% GST) and grand total breakdown.
* **UI & Animations:** Dark-mode glassmorphic theme with hover scaling, drop-shadow effects, and cart entry transitions.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript (ES6+)
* **State Management:** React Context API & `useReducer` Hook
* **Styling:** CSS3 (Flexbox, Grid, Custom Keyframe Animations)
* **Deployment:** Vercel
